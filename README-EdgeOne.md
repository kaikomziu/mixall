# MixAll(Netrify) EdgeOne Pages + Supabase 版

## デプロイ
1. Supabase の SQL Editor で `supabase/schema.sql` を Run(1回だけ)
2. EdgeOne Pages で Direct Upload → この ZIP をアップロード
3. `https://(ドメイン)/api/health` が `{"ok":true}` ならOK
4. `supabase/cron.sql` の `YOUR-SITE` をドメインに書き換えて、Supabase の SQL Editor で Run(定期実行の設定)

## 設定の場所
- Supabase接続情報と cron 用の合言葉: `cloud-functions/_lib/config.js`
- メール(Mailtrap)・AIキーなどは、運営画面の設定 または EdgeOne の環境変数
  (`GEMINI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `MIXALL_EMAIL_API_KEY`, `MIXALL_EMAIL_FROM` など)

## 旧Netlify版との違い
- `/api/*` → `/api/*`
- Netlify Blobs → Supabase(テーブル `kv`)
- このZIPはNetlifyに依存しません(画面のAPIは `/api/*`、OGPは `https://mixalls.edgeone.dev`)
- メールは AgentMail に対応(下の「メール(AgentMail)」参照)。環境変数は不要です。
- x.gd のAPIキーは運営画面の「x.gd APIキー設定」またはツールの短縮URL欄に入力(入力したキーを最優先、失敗時は内蔵キーに自動フォールバック)
- サイトURLは環境変数 `MIXALL_SITE_URL` で上書き可(未設定なら `https://mixalls.edgeone.dev`)
- Background Function → 呼び出し先を短時間で切り離し、取りこぼしは cron の `ai-sweep` が回収
- scheduled function → Supabase pg_cron
- 1回の関数は最大120秒(EdgeOneの上限)

- 送信: 全メールを `mixall@agentmail.to` から送信。送信元のMixAllアドレスは件名の頭 `[〇〇@bix.3erver]` と本文の先頭・末尾に記載

## データ書き出し(Supabase → サイト本体)
- 運営画面 → 「データ書き出し」(主運営のみ)。選んだストアを暗号化したファイルのZIPにして出力します。
- ZIPの中の `data` フォルダをサイトのファイルに足して(既存の `data` フォルダは消さずに)再アップロードすると、サイトの `/data/` から読み取られます(Supabaseに無いデータだけ)。
- そのあと「確認してSupabaseから削除」を押すと、サイト側に同じ内容があるものだけSupabaseから消えます。
- 書き出したデータの編集・削除は、変更分だけSupabaseに記録されます(元のファイルは変わりません)。
- ファイルは暗号化されています。鍵は環境変数 `MIXALL_ARCHIVE_SECRET`(未設定なら内蔵の既定値)。**書き出したあとに値を変えると読めなくなる**ので、変えないでください。
- アカウント・セッション・秘密情報のストアは書き出せません。

## データ書き出し(データ置き場 mixall-data)
- 書き出したデータは別のEdgeOne Pagesサイト(既定: `https://mixall-data.edgeone.dev/`)に置きます。本体サイトのZIPに `data` フォルダは入れません。
- 置き場のURLを変えるときは環境変数 `MIXALL_DATA_URL`(`MIXALL_SITE_URL` とは別です)。
- 運営画面「データ書き出し」で作る `mixall-data.zip` には、置き場に今ある内容 + Supabaseの追加・変更・削除がすべて入っています。**mixall-data にそのまま再デプロイ(置き換え)**してください。その後「確認してSupabaseから削除」で容量を空けます。

- 会社概要(/company)・利用規約(/terms)・プライバシーポリシー(/privacy)を追加。トップのフッターと新規登録画面からリンク
- 複数条件チップ式の検索(`js/filter-search.js`)を追加: ぽけっとルームの「検索」とUchスレッドの「🔍 検索」。from:/has:/mentions:/日付/投稿者タイプを複数組み合わせ可能

## 学校モード(/school/)
- 登録: `/school/register.html`(学校メール判定 → 認証コード → アカウント作成)。API: `cloud-functions/api/school.js`
- 学校メール判定: 世界の大学ドメイン一覧(GitHub: Hipo/university-domains-list を初回に取得して7日キャッシュ)＋ `.edu` `.ac.xx` `.ed.jp` `.k12.xx.us` などのパターン。生徒/教員は、アドレスではなく登録時の確認クイズ(10問: 教員向けの実務知識5問＋最近の流行5問)で判定。教員向け4問以上かつ流行より2問以上多く正解なら教員、流行3問以上かつ教員向けより2問以上多く正解(教員向けは2問以下)なら生徒。流行問題は `cloud-functions/api/school.js` の `STUDENT_Q` を書き換えて入れ替える
- 教員がクラスを作ると学校コードが発行され、同じ学校の生徒がコードで参加
- クイズ: 教員が作成 → 「課題として出す」(期限つき可) または「ライブ」(Kahoot風、制限時間・スピード得点・順位)
- 生徒の画面共有: 教員が依頼 → 生徒が許可して画面を選ぶとWebRTCで教員に表示(生徒はいつでも停止可能)

## ふぉます(マッチング) / バックグラウンド通知 / FANZA・Pornhub (fix8)
- **ふぉます** `/Fomasu` (API: `/api/fomasu`): Ghostと同じく本名ではなく「ふぉます名」+「ID」で出会うマッチングサービス。目的はゲーム・恋愛・友達づくり・話し相手・趣味・勉強・その他。「いますぐマッチング」(同じ目的で待っている人と即マッチ。最大10分待機)、「いま募集中」(さがす一覧に表示)、「さがす→マッチ申請(相互でマッチ)」、マッチ後のチャット、解除・ブロック・通報。マッチ成立・メッセージ・申請はバックグラウンド通知で届く。年齢: 18歳未満と18歳以上は完全に別プール、恋愛は18歳以上のみ、生年月日が未登録だと使えない。通報は `mixall-fomasu` ストアの `r:*` に保存される。
- **バックグラウンド通知(Web Push)**: アプリ・タブを閉じていても端末に表示。`sw.js`(push/notificationclick) + `js/push-client.js` + `/api/push` + `cloud-functions/_lib/push.js`(node:cryptoだけで実装したVAPID/aes128gcm)。通知ページ(`/Notifications/`)の「バックグラウンド通知」でオン/オフ・テスト。通知が作られる箇所(ぽけっと・Uch・運営のお知らせ/警告・Webhook・AI)と、ふぉますの通知から即時に送る。VAPID鍵は `_lib/push.js` に内蔵(環境変数 `VAPID_PRIVATE_JWK` / `VAPID_PUBLIC_KEY` / `VAPID_SUBJECT` で差し替え可。本番では差し替え推奨)。**注意**: Android APK(WebView)はWeb Push非対応。APKで届けるにはFCM(Firebase)を組み込んだネイティブ側の対応が別途必要。ホーム画面に追加したPWA/Chromeでは届く(iPhoneは「ホーム画面に追加」したアプリのみ)。
- **FANZA(DMM)・Pornhub**: MAWS(`/MAWS/`)のプロキシから開ける。18歳以上(生年月日で確認)+成人確認クイズ済み(運営は免除)のログインユーザーだけ。`/api/pixiv` の `adultPass` が署名つき通行証(3時間)を発行し、`/api/px` が通行証のない成人向けホストの要求を拒否、通過時は年齢確認のCookieを付けて取得する。相手サイト側のbot対策などで開けないことはある。
- カラフル設定で下部メニューを開くと画面が虹色になる問題を修正(ナビ系ボタンをグラデーション対象から除外)。

## 容量対策(v22)
- **第2Supabase(直列つなぎ)**: `supabase/schema2.sql` を第2プロジェクトで実行 → EdgeOneの環境変数 `SUPABASE2_KEY` に第2のsecret keyを入れる(URLは config2.js に入力済み)。第1が90%(`SUPABASE_FULL_RATIO`)を超える/書き込み不可になると新規キーは自動で第2へ。読みは 第1→第2→データ置き場。
- **自動圧縮**: `supabase/cron.sql` を(YOUR-SITE を直して)再実行すると `/api/auto-compact` が10分おきに走る。

- **第3Supabase**: 第2も90%を超えたら新しいデータは第3へ(第1→第2→第3の直列)。第3のプロジェクトでも `supabase/schema2.sql` を1回実行。URL/キーは `cloud-functions/_lib/config2.js`(環境変数 SUPABASE3_URL / SUPABASE3_KEY が優先)。
- **第4・第5Supabase**: 第3も満杯に近づいたら順に使う。各プロジェクトで `supabase/schema2.sql` を1回実行。
- **保管場所の台帳**: どのキーが第何Supabaseにあるかを第1の専用ストア `_route` に記録。読み・一覧・削除は台帳を見て目的の場所へ直接行きます(第2〜第5を順に探さない)。初回だけ既存データを台帳に登録します(自動)。

## コドミル(親子の見守りモード) `/Kodomiru`
- 学校モードに似た見守り機能。保護者(18歳以上)が家族コードを作り、子ども(18歳未満)がコードで参加する。どちらも生年月日の登録が必要。
- 保護者ができること: 今日の利用時間(サービス別)の確認 / 1日の利用時間の上限 / 就寝時間(その間は使えない) / 使えないサービスの指定 / 今日だけ+15分・+30分 / 今すぐロック・解除 / 7日間のレポート / 家族コードの作り直し / 見守りの解除。
- 子どもができること: 今日の利用状況とルールの確認(見守り中であることは常に表示)、延長・解除のお願い(保護者へ通知)。

- 仕組み: `js/kodomiru-guard.js`(全ページで子ども側だけ動く)が30秒ごとに `/api/kodomiru` の heartbeat で時間を数え、上限・就寝時間・使えないサービスのときは画面をロック。保護者への通知はバックグラウンド通知(Web Push)で届く。
- 限界: 数えるのはMixAllの中の利用時間だけ(端末全体のスクリーンタイムではない)。子どものアカウントでログインした端末すべてが対象だが、ログアウトして別アカウントを使うことは防げない(アプリ側の見守りであり、端末の制限機能の代わりではない)。

## 通話(TURN・バグ修正) fix1
- TURN: 通話・Ghost配信・学校ハブは `/api/calls` の `ice` からICEサーバーを取得する。優先順: ①Cloudflare TURN(`CF_TURN_KEY_ID`+`CF_TURN_API_TOKEN`) ②Metered(`METERED_DOMAIN`+`METERED_API_KEY`) ③固定(`TURN_URLS`カンマ区切り/`TURN_USERNAME`/`TURN_CREDENTIAL`) ④公開の無料中継(openrelay。不安定なので最後の手段)。**環境変数を設定していないと④になり、携帯回線などでは音が届かないことがある。**
- 修正: `get` が毎回通話データ全体を書き戻していたため、同時に書かれた「応答済み/終了」を古い内容で上書きすることがあった → 期限が半分を切ったときだけ、読み直して期限だけ更新。
- 修正: 信号の取得位置(`after`)を3秒巻き戻して、サーバー間の時計のずれで信号を取りこぼさないようにした(重複はクライアントで除外)。
- 12秒つながらない/接続失敗のときは、サーバー経由の音声中継(WebRTCなし)に自動で切り替わる(既存)。中継はDBに書き込むため、Supabaseの容量が満杯だと動かない。

## 言語切替で画面全体を翻訳 / 緊急モードのデータURL / ツール追加 (fix1)
- **画面全体の翻訳**: 表示言語を変えると、メッセージだけでなく画面の文言(ボタン・見出し・設定・placeholder など)を翻訳する(`js/i18n.js`)。以前は、文言が35件を超えると翻訳APIの間隔制限(700ms)に引っかかり、**ページ全体の翻訳が丸ごと失敗**していた(メッセージ翻訳は1回の呼び出しなので動いていた)。修正: 間隔制限は待って再試行 / 結果が合わないときは半分に分けて再試行 / できた分から順に画面へ反映 / 左上に「Translating…」を表示。サーバー(`/api/tools` の `translate`)は、画面の文言を言語ごとの共通キャッシュ(`trui:<言語>`)に保存し、同じ文言は2回目からAIを呼ばずに返す。i18n.js が無かった画面(通知・ふぉます・コドミル・Ghost投稿作成)にも追加。ユーザーの投稿本文(`.text` など)は従来どおり翻訳しない。
- **緊急モードのURL**: 「オフラインHTMLを開く」で、Blob URLの代わりに **データURL**(`data:text/html;base64,…`)を作る。ページの中身ごとURLになるので、サーバーやネットがなくても開ける。ブラウザによってはページからの直接移動が禁止されるため、URLをコピーしてアドレス欄に貼り付けるか、ブックマークに保存する(画面に表示)。
- **ツール追加** (`js/tools-extra.js`、すべて端末内で動作): パスワード・UUID生成 / ハッシュ・Base64・URLエンコード / 日付計算(日数・加減・曜日・和暦) / 単位変換(長さ・重さ・温度・面積・坪・畳・体積・データ量・時間・速度) / 割り勘 / くじ・ダイス・ルーレット・チーム分け / テキスト差分 / 世界時計・時差 / テキスト変換(全角半角・カナ・重複削除など) / 消費税・割引 / 文字色コントラスト比 / ストップウォッチ・カウントダウン。
- **読み込みマーク**: 通常の通信は9秒以上かかったときだけ表示(以前は4秒)。通話・コドミル・ふぉます・翻訳などの裏の通信では出さない。
