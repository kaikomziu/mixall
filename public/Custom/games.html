HTMLファイル(またはzip・フォルダ)をアップロードすると、MixAllの中で遊べます。ゲーム内からデータを保存するしくみ(MixAllCustom)も使えます。

ここに .html / .zip / フォルダ をドロップ、または選択

公開すると、年齢や安全性の確認(自動・運営)が行われることがあり、確認が済むまで他の人には表示されない場合があります。1ファイル1.5MBまで・合計4MBまで。外部サイトへの通信はできません(安全のため)。

ゲームからデータを保存したいとき

ゲームのJavaScriptの中で、次のように書くと保存・読み込みができます(ログインしている人ごとの保存と、みんなで共有する保存を選べます)。

// 自分だけのセーブ(既定)
await MixAllCustom.save('score', { best: 120 });
const d = await MixAllCustom.load('score');   // 未保存なら null

// みんなで共有する保存(オンライン用)
await MixAllCustom.save('room:1', { turn: 3 }, { scope: 'game' });
const all = await MixAllCustom.list('room:');  // [{key, value, updatedAt}]
await MixAllCustom.remove('room:1');

MixAllCustom.user // { name, id }
