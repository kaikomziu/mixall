MixAll Web Search (MAWS)

登録されたWebページと、MixAllのGhost投稿をまとめて検索します。入力欄をタップすると、キーワードに site / 投稿者・日付・種類 などの条件を重ねて絞り込めます。結果は関連度の高い順に並びます。

MAWSプロキシ

PlayStationなど、サイト側にbot扱いされやすい端末でも開けるように、MixAllのサーバー経由でページを表示します。URLかキーワードを入れてください（/MAWS/?ServerAction=https://example.com でも開けます）。pixivは専用のpixiv画面で開きます。ログインやパスワード入力は使えません。

pixiv　FANZA (18+)　Pornhub (18+)

URLを登録して検索に載せる

URLを入れるだけで登録できます(所有権の確認は不要)。登録後にURLを編集・削除する管理機能はありません。ページのタイトル・説明・本文の冒頭を保存して検索に使います。noindexのページ、HTML以外、公開されていないアドレスは登録できません。登録できるのは1日20件までです。
