拡張機能管理

Chrome拡張機能のように、運営が登録したJSONパッケージをサーバーから配布できます。パッケージはサンドボックス内で実行され、停止・削除もここから行えます。拡張機能ストアと拡張機能データストアはバックアップ対象です。

JSON形式: {"id","name","version","description","author","icon","permissions","manifest","bundle"}

Google検索連携（MAWS）

MAWSの検索にGoogleの結果を足します。Google Programmable Search Engine（「ウェブ全体を検索」にしたもの）の 検索エンジンID(cx) と、Custom Search APIの APIキー を入力してください。無料枠は1日100回までなので、MixAll側で1日95回に制限しています。未設定のときは「Googleで開く」リンクだけが出ます。

x.gd APIキー設定

短縮URL（x.gd）の発行で最優先に使うAPIキーです。x.gdのAPIキーは24時間使われないと自動で無効になるため、切れたらここで入れ直してください（ツールの短縮URL欄から入力しても運営ログイン中なら同じ値が保存されます）。入力したキーが使えない場合は、内蔵キーへ自動で切り替わります。空欄で保存すると保存済みキーを削除します。

初回設定(SQLを1回実行)

SupabaseのSQL Editorで、下のSQLを貼って実行してください。そのあと「更新」を押します。

最大容量は既定で500MB(無料プラン)。プランが違う場合は、環境変数 SUPABASE_DB_LIMIT_MB(MB単位)を設定してください。

データ書き出し(Supabase → データ置き場 mixall-data)

Supabaseの容量を空けるための機能です(主運営のみ)。書き出したデータは別サイト https://mixall-data.edgeone.dev/(データ置き場)に置き、本体サイトはそこを読みに行きます。①「一覧を読み込む」 → ②Supabaseに溜まった追加・変更分を書き出したいストアにチェックして「ZIPで書き出す」 → ③できた mixall-data.zip を mixall-data にそのまま再アップロード(置き換え) → ④「確認してSupabaseから削除」。ZIPには「データ置き場に今ある内容 + Supabaseの追加・変更・削除」がすべて入っているので、毎回新しい保存先を作る必要はありません(チェックしていないストアも、今ある内容はそのまま引き継ぎます)。本体サイト側のZIPに data フォルダは不要です。書き出し後に編集・削除した分は、次回の書き出しまでSupabaseに残り、そのまま優先して使われます。

Geminiの固定プロンプト・権限

固定プロンプトには「@u123... は運営」など、応答時に常に参照させたい説明を記入できます。参照対象は閲覧可能なUchスレッドと公開Ghost投稿のみです。Mail・Pocket個人チャット・アカウント情報や非公開スレッドはGeminiに渡しません。現在開いているUchスレッドの会話履歴は回答に必要な範囲で常に使います。

公式アカウント・自動応答プログラム

運営・副運営専用。公式アカウントはPocket・Ghost・Uch・Mailの各チャンネルに接続できます。トリガー成立後、conditionsで送信者・本文・履歴・ルーム/スレッド・添付・返信・曜日/UTC時間帯・Ghost投稿状態まで絞り込めます。任意のJavaScriptは実行せず、宣言型ルールで登録します。

運営ログインメール変更

主運営のみ利用できます。変更すると、保存済みデータ内の所有者・投稿者・参加者などの旧アドレスを新アドレスへ移行し、旧アドレスはログイン別名として保持します。既存の運営ログイン端末はすべて失効するため、完了後は新アドレスで再ログインしてください。

アカウント・運営権限・公認バッジ・パスワード再設定

「運営」は主運営と副運営は同等の運営権限を持ち、全データのバックアップ・復元、運営・副運営の任命・解除を行えます。

毎月、GeminiがCustomのプログラムと公開サイトのHTMLを確認し、淫夢関連・性的内容・その他の年齢注意内容をGhostと同じ年齢カテゴリで判定します。危険な挙動の兆候は人手確認へ回します。外部画像・動画はAIが直接確認できないため、その旨を表示します。運営・副運営はソースを確認し、許可または停止と年齢カテゴリを手動設定できます。
