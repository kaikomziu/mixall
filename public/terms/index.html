利用規約

制定日: 2026年10月20日 ／ 最終改定日: 2026年10月21日

この利用規約（以下「本規約」）は、BoxMedia（以下「当社」）が提供する「MixAll」およびその関連サービス（以下「本サービス」）の利用条件を定めるものです。本サービスを利用する方（以下「ユーザー」）は、本規約に同意したうえで利用するものとします。

第1条（適用）

本規約は、ユーザーと当社との間の本サービスの利用に関わる一切の関係に適用されます。当社が本サービス上で別途定めるルールやガイドラインは、本規約の一部を構成します。

第2条（アカウント）

  1. ユーザーは、正確な情報を登録し、アカウントを自己の責任で管理するものとします。
  2. パスワードや認証情報を第三者に貸与・譲渡・共有してはなりません。
  3. アカウントの利用により生じた結果については、ユーザー自身が責任を負います。ただし、当社の故意または重大な過失による場合を除きます。
  4. 年齢に関する確認が必要な機能については、当社が定める方法で確認を行うことがあります。

第3条（禁止事項）

ユーザーは、本サービスの利用にあたり、次の行為をしてはなりません。

  • 法令または公序良俗に違反する行為
  • 他のユーザーまたは第三者への誹謗中傷、脅迫、嫌がらせ、差別、プライバシーの侵害
  • 他人の著作権、肖像権、商標権その他の権利を侵害する投稿・送信
  • わいせつ、過度に暴力的、または児童の安全を脅かすコンテンツの投稿・送信
  • なりすまし、虚偽の情報の流布、詐欺的行為
  • スパム、迷惑メール、過度な連続投稿、自動化による不正なアクセス
  • 本サービスのサーバーやネットワークに過度な負荷をかける行為、不正アクセス、脆弱性の悪用
  • コンピュータウイルスその他の有害なプログラムの送信
  • 本サービスの運営を妨害する行為
  • 前各号を助長する行為、その他当社が不適切と判断する行為

第3条の2（アダルトコンテンツ等と年齢による表示）

本サイトは、アダルトコンテンツ等を一切禁止しておりません。ただし、アカウント作成時に登録された年齢（生年月日）によって、表示される内容の範囲（表示度）が変わります。18歳未満のユーザーには、成人向けの内容が表示されない、または利用できない機能があります。

  • 年齢の登録内容は正確である必要があります。虚偽の年齢を登録して制限を回避する行為は禁止します。
  • 登録年齢に誤りがある場合、運営は確認のうえ登録内容を修正することがあります。
  • 成人向けの内容を投稿する場合は、法令（わいせつ物の頒布の禁止、児童の保護に関する法令など）および本規約の禁止事項を守ってください。児童を性的に描写する内容、実在の人物の同意のない内容、違法な内容は成人向けであっても禁止です。
  • 外部サイトの内容（pixiv等）を表示する機能でも、年齢や本人確認に応じた制限が適用されます。

第4条（投稿コンテンツ）

  1. ユーザーが投稿・送信したコンテンツの権利は、ユーザーまたは正当な権利者に帰属します。
  2. ユーザーは、本サービスの提供・運営・改善に必要な範囲で、当社がそのコンテンツを保存、複製、表示、配信することを許諾するものとします。
  3. 当社は、本規約に違反する、または違反するおそれがあるコンテンツについて、事前の通知なく非表示または削除できるものとします。
  4. ユーザーは、投稿内容について自ら責任を負うものとします。

第5条（コミュニケーション機能）

  1. ぽけっと・Uch・Mailなどの機能における送受信内容は、通報への対応、不正利用の調査、法令に基づく要請への対応のため、当社が必要な範囲で確認することがあります。
  2. Mail機能でGmailなど外部のメールアドレスと送受信する場合、メールは外部のメール配信サービスを経由して配送されます。外部宛のメールの送信回数には上限を設けることがあります。
  3. ぽけっとの友達追加URLは、第三者に知られると友達追加を受ける可能性があります。URLの取り扱いはユーザー自身の責任で行ってください。

第6条（AI機能・自動応答）

本サービスには、AIやbotによる自動応答機能が含まれる場合があります。AIの出力は正確性・完全性を保証するものではなく、ユーザーは自己の判断で利用するものとします。

第7条（Coin・スタンプ等）

本サービス内のCoinやスタンプ等は、本サービス内でのみ利用できる仮想的なものであり、現金その他への換金はできません。付与・購入の条件、有効期限等は、本サービス上の表示に従います。

第8条（ブラウザ・端末機能の利用）

  1. 本サービスは、次の機能を使うときに限り、ブラウザや端末の許可を求めます。許可は任意で、許可しなくてもその機能以外は利用できます。許可は、ブラウザや端末の設定からいつでも取り消せます。
    • 位置情報: ぽけっとの現在地・目的地の送信、緊急モニター（ユーザーが有効にした場合のみ）
    • マイク・カメラ: 通話、音声メッセージの録音、Ghostのライブ配信
    • 画面共有: 通話中の画面共有
    • 通知: 通知機能を有効にしたとき
    • ブラウザストレージ・Service Worker: ログイン状態や設定の保存、表示の高速化、緊急機能
    • クリップボード（書き込みのみ）、バイブレーション
  2. 位置情報や映像・音声を他のユーザーへ送る操作は、ユーザー自身の判断と責任で行うものとします。送信前に、相手と内容をよく確認してください。
  3. 各機能で取り扱う情報の詳細は、プライバシーポリシーに定めます。

第8条の2（承認制スレッド・Wiki・一時機能）

  1. Uchの承認制スレッドでは、参加を希望するユーザーのアドレス・表示名・ひとことが、スレ主と運営に表示されます。承認・却下はスレ主の判断で行われ、当社は個々の判断について責任を負いません。
  2. みんなのWikiに投稿した内容は、誰でも閲覧できる状態で公開されます。他者の権利を侵害する内容や、個人情報を載せないでください。編集・削除は作成者のみ行えます。
  3. 一時チャットルーム・一時共有ロッカーは、URLを知る人が誰でも閲覧できます。個人情報や機密情報を送らないでください。一定時間で利用できなくなりますが、完全な削除までに時間がかかる場合があります。
  4. 匿名メッセージ箱への送信内容は、当社が不正利用の調査のために確認することがあります。

第9条（外部サービス・広告）

  1. 本サービスは、広告を表示しておらず、Google AdSenseなどの広告配信サービスも利用していません。
  2. 本サービスは、ホスティング、データ保管、メール配信、AI機能、地図表示、動画の埋め込みなどに、外部サービスを利用しています。利用している外部サービスと、送られる情報は、プライバシーポリシーに記載します。
  3. 本サービスには、外部サービスへのリンクが含まれる場合があります。外部サービスの利用は、各サービスの規約等に従うものとし、当社はその内容について責任を負いません。

第10条（サービスの変更・停止）

当社は、保守、障害、法令の変更その他の事情により、ユーザーへの事前通知なく本サービスの全部または一部を変更、中断または終了することがあります。これによりユーザーに生じた損害について、当社は、当社の故意または重大な過失による場合を除き責任を負いません。

第11条（利用制限・アカウントの削除）

ユーザーが本規約に違反した場合、またはそのおそれがあると当社が判断した場合、当社は、事前の通知なく、コンテンツの削除、利用の制限、アカウントの停止・削除を行うことができます。ユーザーは、アカウント設定からいつでもアカウントを削除できます。

第12条（免責）

  1. 当社は、本サービスが常に中断なく、エラーなく、安全に提供されることを保証しません。
  2. ユーザー間または、ユーザーと第三者との間に生じたトラブルについて、当社は責任を負いません。
  3. 当社の責任は、当社に故意または重大な過失がある場合を除き、法令で認められる範囲で免除されます。ただし、消費者契約法その他の法令により免責が認められない場合は、この限りではありません。

学校モードについて（追加条項）

  1. 学校モードは、学校から発行されたメールアドレスを持つ方が利用できます。生徒・教員の区分は、登録時の確認クイズの結果によって判定します（学校のアドレスは生徒と教員で同じドメインの場合があるためです）。申告内容が事実と異なる場合、当社は利用を制限できます。
  2. 教員は、学校コードで参加した生徒に対し、クイズの出題・画面共有の依頼ができます。画面共有は、生徒がブラウザの確認画面で許可した場合にのみ開始され、生徒はいつでも停止できます。教員は、画面共有で知り得た情報を教育目的以外に使用したり、録画・撮影・第三者への提供をしてはなりません。
  3. 学校コードは、クラスに参加する生徒以外に共有してはなりません。
  4. クイズの内容や回答の不正（他人へのなりすまし、自動回答等）は禁止します。

第13条（規約の変更）

当社は、必要と判断した場合、本規約を変更できます。変更後の規約は、本サービス上に掲載した時点から効力を生じます。変更後も本サービスを利用した場合、ユーザーは変更後の規約に同意したものとみなします。

第14条（準拠法・管轄）

本規約は日本法に準拠します。本サービスに関して紛争が生じた場合は、当社の所在地を管轄する裁判所を第一審の専属的合意管轄裁判所とします。
